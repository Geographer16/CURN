CURN Toolbox Installation and User Guide

When you add the CURN toolbox to ArcGIS Pro, a red exclamation mark may appear next to it. This issue usually occurs because the required Python libraries (joblib and xgboost) are not installed on your system.
Follow the steps below to install the necessary libraries and get the tool working.

1. Verifying the Cause of the Error
•	Right-click on the CURN toolbox displaying the red exclamation mark.
•	Click Check Syntax (the second option from the top) in the context menu.
•	Confirm the missing library notification (Module Not Found Error) in the pop-up window.

2. Cloning the ArcGIS Pro Python Environment ArcGIS Pro does not allow installing libraries directly into the default Python environment. Therefore, you must first create a copy of the environment:
•	Click the Project tab in the top-left corner of ArcGIS Pro.
•	Select Package Manager from the left menu.
•	Click the gear icon (settings) next to the Active Environment section in the top-right corner to open the Environment Manager window.
•	Click the three dots (...) next to your currently active Python environment and select Clone (online) (ensure you have an active internet connection).
•	Wait for the cloning process to complete. A green checkmark in the Tasks window at the bottom-right indicates completion.
•	Click the three dots (...) next to the newly created cloned environment and click Activate to set it as active.
•	Close the Environment Manager window.

3. Installing Required Libraries (joblib and xgboost)
•	Click the Add Packages tab at the top of the Package Manager page.
•	Type joblib into the search box and click the corresponding result.
•	Click Install in the right-hand panel to start the download.
•	Once the installation is complete, search for xgboost in the same search box and follow the same steps to install it.
•	After installing both libraries, restart ArcGIS Pro.

4. Using the CURN Tool The CURN tool requires input data generated by the HydroMachine software to run properly.
•	HydroMachine Data Preparation: Run the following tools sequentially in HydroMachine to generate the base data:
o	FlowD8
o	Stream Generation

•	Running the CURN Tool: Reopen ArcGIS Pro and re-add the CURN toolbox. Use the generated stream network layer as input to detect unrealistic stream networks.
